# Crash / Stability Audit — 2026-09-18 (E2E, admin screens included)

**Scope:** Whole app, this pass adds full admin surface (`src/pages/Admin*.tsx`,
`src/features/admin/**`, `src/features/admin-upload/**`, `src/components/admin/**`)
on top of the prior student PDF/video pass.

**Overall rating: PASS — no crash-causing defects found.** The codebase already
carries a mature crash-shield (`src/lib/crashShield.ts`), a cooldown-guarded
`ErrorBoundary`, and consistent cleanup discipline. No code changes were
required; this report documents verification only.

## 1. PDF viewer teardown / video release / blob URLs / IndexedDB / query cache
- `src/lib/perf/queryPersister.ts` — cache is hard-capped at 4 MB, evicts
  oldest-first when over budget, skips realtime/session keys, guards against
  non-serializable data (Set/Map), and `startQueryPersister` returns a
  disposer that clears its `setInterval` and removes its
  `visibilitychange` listener. **PASS**.
- `src/components/admin/MediaPreview.tsx:28-30` — `createObjectURL` is paired
  with `revokeObjectURL` inside the effect cleanup. **PASS**.
- `src/pages/Admin.tsx:324`, `src/pages/LessonView.tsx:2040,2134` — export/CSV
  and lecture blob URLs are revoked via `setTimeout(revokeObjectURL, …)`.
  **PASS** (previously audited student-side, re-confirmed here).
- No admin screen mounts `PdfViewer`/`FastPdfReader`/video players directly
  without going through the same lazy wrappers already covered by the prior
  audit.

## 2. Promise chains / async effects without catch
- Found bare `.then()` calls without `.catch` in `AdminStudyMaterials.tsx`,
  `AdminUpload.tsx`, and `TimetableManager.tsx` (all Supabase
  `select().then(({data,error}) => …)`). Supabase's query builder resolves
  (never rejects) except on abort/network failure; any such rejection is
  already caught by the global `unhandledrejection` trap in
  `crashShield.ts`, which explicitly whitelists network/abort/timeout
  patterns so it won't force a reload. **PASS**, no action taken (adding
  `.catch` everywhere would be cosmetic, not a stability fix — flagged as
  optional low-priority cleanup, not applied to keep the diff minimal).

## 3. addEventListener / setInterval / setTimeout / supabase channel / Capacitor listener cleanup
Audited every occurrence app-wide (`rg` across `src`), admin included:
- `LiveClass.tsx`, `TeacherLiveView.tsx`, `Messages.tsx`, `AllLive.tsx` —
  all `supabase.channel(...)` subscriptions are torn down via
  `supabase.removeChannel(channel)` in the effect cleanup. **PASS**.
- `AdminLiveManager.tsx`, `AdminBatchMonitor.tsx`, `AdminFraudWatch.tsx` —
  no raw `setInterval`/manual polling; effects run once per dependency
  change and don't leak timers. **PASS**.
- `src/hooks/useAndroidBackButton.ts` — module-level singleton guards
  against StrictMode/HMR double-registration; listener is registered once
  per app lifetime, decrements a ref-count on unmount, and only tears down
  the native listener when `activeHookCount` reaches 0. **PASS**.
- `src/components/SplashHider.tsx` — 800 ms hard safety timeout,
  `cancelled` flag + `clearTimeout` in cleanup, double-hide guarded by
  `hidden.current`. **PASS**.
- `BackButtonDebug.tsx` interval/listener, `Install.tsx`
  `beforeinstallprompt`/`appinstalled`, `LessonView.tsx`
  `visibilitychange`/`pagehide`/`popstate`, `MyCourses.tsx` `focus` — all
  paired with matching `removeEventListener`/`clearInterval` in their
  effect cleanups. **PASS**.

## 4. Main-thread blocking sync work
- Admin analytics/stats helpers (`adminStats.ts`, `adminFilters.ts`) are
  small (≤200 lines), operate on already-paginated Supabase result sets, and
  contain no unbounded loops, `JSON.stringify` of large payloads, or base64
  encode/decode of big binaries. **PASS**.
- No `FileReader.readAsDataURL` / base64 conversion found in
  `admin-upload` — uploads go straight to Supabase Storage via signed URLs.
  **PASS**.

## 5. ErrorBoundary retry guard / crashShield watchdog
- `src/components/ErrorBoundary.tsx` — auto-reload only fires for a
  whitelisted set of transient error messages, cooldown mirrored to both
  `sessionStorage` and `localStorage` (survives WebView process death), and
  the manual "Refresh" button explicitly clears all reload-cooldown keys so
  a user is never locked out of recovery. "Go Back" falls back to `/` when
  there's no real history (avoids `about:blank` white screen). **PASS**.
- `src/lib/crashShield.ts` — heartbeat watchdog correctly suppresses
  false positives while `document.hidden` (avoids reload storms from OS
  throttling on backgrounding), reload is capped at 1/60s across both
  storages, and the rejection-count threshold excludes expected
  network/abort/`UNIMPLEMENTED` errors. **PASS**.

## 6. Capacitor lens
- `capacitor.config.ts:18,22` — `webContentsDebuggingEnabled:
  process.env.CAP_DEBUG === "1"` (off unless explicitly opted in for a debug
  build). **PASS**.
- `android/app/src/main/res/xml/network_security_config.xml` —
  `cleartextTrafficPermitted="false"` at base and per-domain config; no
  blanket cleartext allowance. **PASS**.
- Capacitor plugins are only ever touched through the memoized lazy loaders
  in `src/lib/native/*` (`app.ts`, `preferences.ts`, etc.), each wrapped in
  `try { … } catch { /* web fallback */ }` at call sites (verified in
  `queryPersister.ts`, `useAndroidBackButton.ts`). No admin screen imports
  `@capacitor/*` directly. **PASS**.
- No `fixed`/`sticky` viewport-anchored bars found in the admin surface;
  the one `sticky top-0` table header (`PaymentsSection.tsx:291`) is
  anchored to a scrollable container, not the viewport, so it doesn't need
  safe-area insets. **PASS**.
- Back-button handler is mounted exactly once per app lifetime via the
  module-level singleton in `useAndroidBackButton.ts`. **PASS**.
- `SplashHider.tsx` has an 800 ms hard timeout independent of
  fonts/auth/network. **PASS**.
- FLAG_SECURE / screen-capture protection hooks
  (`useScreenProtection.ts`, `useWebScreenshotShield.ts`,
  `useScreenCaptureDetection.ts`) are wired into paid video/PDF surfaces
  (`PdfViewer.tsx`, `FastPdfReader.tsx`, `LiveClass.tsx`,
  `ArchiveBookReader.tsx`) as well as `AdminSecurity.tsx` for the admin
  security settings screen. **PASS** (re-confirmed, not newly added).
