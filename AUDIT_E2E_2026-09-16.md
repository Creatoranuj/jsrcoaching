## 2. Findings

### [HIGH] [SEC/CONFIG] Source maps ship inside the release APK
**Where:** `vite.config.ts:163` (`sourcemap: "hidden"` in production) + `.github/workflows/build-apk.yml` (no `.map` cleanup before `cap sync`).
**Why it matters:** 331 `.map` files (28 MB raw) land in `assets/public/assets/` of the signed APK. Anyone who unzips the APK gets the full, readable application source — business logic, admin flows, payment handling. It also inflates every download.
**Fix:** after the Sentry sourcemap upload step and before `npx cap sync android`, run `find dist -name '*.map' -delete`. Sentry already has the maps server-side, so symbolication is unaffected.

### [HIGH] [PERF] pdf.js shipped twice
**Where:** `android/app/src/main/assets/pdfjs/` (19 MB) and `assets/public/pdfjs/` (6 MB, from `public/pdfjs`).
**Why it matters:** two full pdf.js distributions (build + web viewer + `.map` + sandbox) inside one APK. Only one is loaded at runtime.
**Fix:** keep the copy the reader actually loads, delete the other from the build pipeline; also strip `*.map` and the 992 KB `compressed.tracemonkey-pldi-09.pdf` demo document from whichever remains.

### [MEDIUM] [CI] Deprecated Node 20 actions in three workflows
**Where:** `unit-tests.yml` (`checkout@v4`, `upload-artifact@v4`), `typecheck-build.yml` (`checkout@v4`), `lighthouse-ci.yml` (`checkout@v4`, `setup-node@v4`, `cache@v4`).
**Why it matters:** Node 20 is force-migrated and slated for removal — today a warning, later a hard failure. The rest of the fleet is already on v5/v6/v7.
**Fix:** bump to the node24 majors used by the sibling workflows.

### [MEDIUM] [PERF] Sentry is in the initial vendor graph
**Where:** `vendor-sentry` = 150 KB gz, the single largest chunk.
**Why it matters:** on a 3G mid-range phone this is pure startup cost for a tool that reports errors, not renders UI.
**Fix:** lazy-init Sentry behind `requestIdleCallback` / dynamic import after first paint.

### [MEDIUM] [PERF] Charts bundle loaded outside admin
**Where:** `vendor-charts` = 110 KB gz.
**Why it matters:** charts are an admin/reporting concern; students pay the download cost.
**Fix:** ensure every chart import sits behind a lazily-loaded admin route.

### [MEDIUM] [MAINT] Version drift
**Where:** `package.json` says `1.6.0`; git tags are at `v1.6.4`.
**Why it matters:** the in-app version string and crash reports will not match the released build.
**Fix:** bump `package.json` on each release tag, or derive it from the tag in CI.

### [MEDIUM] [MAINT] God components
**Where:** `src/pages/LessonView.tsx` (96 KB), `components/admin/ContentDrillDown.tsx` (68 KB), `components/video/MahimaGhostPlayer.tsx` (68 KB), `pages/AdminUpload.tsx` (67 KB).
**Fix:** split by concern — these are the files where every future regression will land.

### [LOW] [OBS] 138 raw `console.*` calls in `src/`
**Fix:** route through `src/lib/logger.ts` / `reportError` so production stays quiet and Sentry keeps signal.

### [LOW] [MAINT] 60 `as any` casts
**Fix:** most sit on Supabase query results — regenerate types and remove the casts to catch schema drift at build time.

### [LOW] [VIS] 59 `.tsx` files contain hardcoded colors (`text-white`, `bg-black`, raw hex)
**Fix:** move to semantic tokens so dark mode and rebranding don't need a sweep. (New JSR cream/gold branding makes this more likely to show.)

### N/A — Database lens
Supabase project is not linked to the Lovable workspace, so slow-query and index analysis could not be run. Re-run after linking.
